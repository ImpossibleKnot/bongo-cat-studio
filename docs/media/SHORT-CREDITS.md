# Tiny Studio Short: credits and provenance

**Bongo Cat’s Tiny Studio — by [Impossible Knot](https://github.com/ImpossibleKnot).**

[Full 32-second Short with sound](https://github.com/ImpossibleKnot/bongo-cat-studio/releases/download/v0.4.0-rc1/Tiny-Studio-Short.mp4). `tiny-studio-short-preview.gif` is a silent, four-second excerpt of its opening. The README uses the original `studio.gif` firmware animation. The MP4 is attached to the existing `v0.4.0-rc1` release as promotional media; it does not change that firmware build.

- **Animation and sound:** captured together from a fresh native emulator running the actual Tiny Studio C renderer and audio engine. The original 120 BPM demo uses the firmware’s meow, keys, bass, drums, marimba and chiptune sounds. No private user jam or microphone recording was used.
- **Hardware reconstruction, 0–4 seconds:** an animated screen composite. The captured display is fitted into the LCD of an official M-VAVE FM-1 product photograph, and both move together through the zoom. This is not camera footage of a physical performance. The video labels the opening “REAL FIRMWARE / SCREEN COMPOSITE”.
- **Hardware photograph:** M-VAVE, [official FM-1 product page](https://www.m-vave.com/product?id=fm-1), [original image](https://www.m-vave.com/images/productInfo/fm-1-2.webp), retrieved 24 October 2026. The photograph retains its own copyright; the project does not grant GPL rights to it. It is not included in the firmware or the original firmware release bundles.
- **Foundation:** Felucca by Leo Kuroshita / Hügelton Instruments and contributors. See [the full project credits](../../CREDITS.md) and [licensing](../../LICENSING.md).
- **Typography:** Inter Tight, SIL Open Font License 1.1; [licence text](../../LICENSES/OFL-InterTight.txt).
- **Editing:** native, editable Tesseract composition. Music and picture retain the original capture clock; the soundtrack was levelled for the Short. The closing card identifies Impossible Knot and the new repository URL.

The full MP4 is 1080 × 1920, 30 fps, H.264 with stereo 48 kHz AAC. The preview is 324 × 576, 12 fps. The separate `.sha256` release asset covers the MP4; existing firmware checksums remain unchanged.

The firmware and original procedural cat art retain their existing licences. No M-VAVE endorsement is implied.
